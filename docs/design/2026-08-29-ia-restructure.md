# MedKit IA 重组与卡片刷题设计（2026-08-29 · v0.8 → 刷题利器）

> 依据：`docs/reviews/gap-audit-prd-2026-08-29.md` + 已拍板 5 项决策（桌面形态卡片刷题 /
> 复用现有 API / rating 0~5 保留做映射 / 真题标注本期做 / 文档入库）。
> 交付顺序：批次 B（本文件 + 5 Tab 重组）→ C（卡片刷题）→ D（视觉）→ E（真题标注）。

## 1. 功能分级表（交接配置任务 2.1 交付物）

| 级别 | 定义 | 功能 |
|---|---|---|
| **P0 核心刷题/生成** | 用户每周都要用的核心链路 | 新建课题（上传→预设→生成→审核→产物）、刷题（复习卡/记忆卡/押题卷错题重练）、今日任务（仪表盘）、错题本、薄弱组卷 |
| **P1 学习闭环** | 提升效果但非每日必需 | 讲解产物、提问式学习、大纲覆盖、真题考频、掌握度诊断、统计 |
| **P2 设置与高级** | 配置型/一次性 | 连接服务商（API Key/OCR/网络检索）、提示词编辑器、素材库管理、数据管理（备份/导入导出）、主题、更新检查、门禁规则速览 |

收纳原则（DP-01 少即是多）：P2 全部进「我的」；P1 留在学习中心子导航（一屏一任务）；P0 暴露在主侧栏与仪表盘。

## 2. 目标信息架构（桌面侧栏 5 Tab，替代现有 5 Tab）

| Tab（新） | Ctrl 键 | 内容 | 数据来源 |
|---|---|---|---|
| **开始** `start` | 1 | 仪表盘：今日待复习/今日新卡/今日已完成 + 「开始学习」大按钮（→刷题）+ 考试倒计时（可设日期）+ 最近项目（3 个，点击直达项目详情） | `/api/library/dashboard` + `/api/projects`；考试日期存 localStorage `medkit-exam-date` |
| **刷题** `study` | 2 | 科目卡片行（SubjectCard：科目名+复习卡数+掌握率，点击过滤）→ 今日到期复习流（原学习中心「复习计划」视图迁入：SM-2 复习卡 + FSRS 记忆卡 + 铺卡入口） | `/api/library/subjects`（扩展 stats）+ `/api/library/review/today` 等 |
| **题库** `bank` | 3 | 原「新建课题」+「我的项目」合并：上半新建课题表单，下半项目列表/详情/审核台 | 原 proj + mine 全量迁入 |
| **学习中心** `learn` | 4 | 概览 / 错题本 / 讲解产物 / 提问学习 / 大纲覆盖（含真题考频）——去掉「复习计划」子视图（迁入刷题） | 原 learn 六视图减一 |
| **我的** `mine` | 5 | 原「连接服务商」+「提示词与规则」+ 数据管理入口 | 原 conn + prompts 迁入 |

- 默认落地 = **开始**（首启向导仍按原逻辑弹出；无 Key 向导跳「我的」）。
- 快捷键：Ctrl/⌘+1..5 按新顺序；学习中心子导航 Alt+1..5（去复习计划）。
- 侧栏徽章：**刷题** tab = 今日到期复习数；**学习中心** tab = 进行中提问会话数（`setLearnNavBadge` 拆双徽章）。

## 3. 各批次范围与验收

### 批次 B（本文件 + 重组）
- 5 Tab 重组（上表）；showTab 映射：start→loadStart / study→loadStudy / bank→loadProjects+ratioSum / learn→loadLibrary（去 review）/ mine→loadPrompts；切走 bank 停止项目轮询。
- 开始仪表盘：统计卡（due/new/done/掌握率）+ 开始学习按钮 + 倒计时 + 最近项目。
- 验收：浏览器用例 hash 直达 5 tab 均内容就绪；Ctrl+1..5 正确；旧用例按新 tab 更新后全绿；`verify.cmd` 全绿。

### 批次 C（卡片刷题）
- SubjectCard（`/api/library/subjects` 增 `stats`：每科 review_total/review_due/mistakes/mastered_rate）。
- QuestionCard 3D 翻转（CSS rotateY ≤300ms）：正面 = 题干+选项（X 型 checkbox/单选 radio）+「显示答案」；背面 = 答案+解析（关键词高亮：首选药/金标准/确诊等，配置化 `KEYWORDS`）+ 三按钮。
- 三按钮（红 #EF4444 忘了 / 黄 #F59E0B 模糊 / 绿 #10B981 记住）映射现有 quality：忘=0/1、糊=2、记=3/4/5（记忆卡四档沿用重来/困难/良好/简单）；快捷键 1/2/3。
- 顶部进度条：今日 X/Y（X=已评卡数，Y=今日到期数）；评分后即时动效（按钮缩放+toast）。
- 验收：复习卡今日到期 → 卡面翻转 ≤300ms、三按钮评级正确落库（复用 `/api/library/review/grade`）、进度条随评变化；`test_cards.py` 增三按钮映射单测。

### 批次 D（视觉统一）
- 主色青绿 #2A6B5A（PRD 7.2），强调/悬停/主按钮换青绿；保留三按钮语义色。
- 字号收敛 4 级：21（页面标题）/16（卡片标题）/14（正文）/12（辅助）；间距 4/8/12/16/20/24。
- 验收：明暗主题切换无对比度问题；390px 窄屏无溢出（现有用例已覆盖）。

### 批次 E（真题标注，决策 4 本期做）
- 迁移 v6：`realexam_freq` 增 `year`（可空）；`realexams.analyze` 从句/段落提取 `(19|20)\d{2} 年?`（段落级优先）。
- `QuestionItem` 增可选 `source_year`/`source_type`（None 默认，不破坏旧产物）；渲染层：题库/押题卷/审核台显示「20XX 真题」/「高频考点」标签（有标注时）。
- 标注来源（零 LLM）：出题后由审核台/渲染前本地后处理——题目 subtopic/kp 命中已确认 realexams 条目 → source_type="真题" + source_year=该条目最高频年份。
- 筛选器：题库页年份/题型筛选（type 已有字段直接筛；年份空值显示「未标注」），localStorage 按项目记忆。
- 验收：`test_realexams.py` 年份提取用例；`.apkg/.txt` 不回归；产物页标签渲染断言。
