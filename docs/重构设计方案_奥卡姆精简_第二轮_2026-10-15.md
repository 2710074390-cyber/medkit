> **方法**：奥卡姆剃刀——「如无必要，勿增实体」。判据不是「这功能好不好」，

### 1.3 为什么"删代码"不是主要成本（三条实测）

1. **模块级死模块 0 个**：AST 收集全仓（含 `tests/`、`pack/`）的 import 名，
   `medkit/**/*.py` 里**没有一个模块是没人 import 的**。
   ⇒ 想靠"找出没人用的文件"来精简，**在本仓无效**。
2. **前端死分片 0 个**：`js/` 下 14 个文件全部被 `index.html` 的 `<script>` 加载。
   ⇒ 没有"删掉某个 js 文件"这种便宜可捡。
3. **测试是零使用模块的"生命维持系统"**：零数据域的模块被彼此 import、被测试覆盖，
   所以"被引用"永远为真。**删功能必须先删它的测试与守卫**，否则会一直显示"活的"。

## 2. 用户核心链路：现状 vs 应有

### 2.1 应有链路（五环，每环一个目标）

| # | 环节 | 用户目标（他脑子里想的一句话） | 现状 | 摩擦 |
|---|---|---|---|---|
| 1 | **导入题库** | "把我手上的 md 题库收进来" | 「刷题」页 → 导入 → 解析预览 → 入库 | ✅ 顺（v10 起存原文可重解析） |
| 2 | **刷题** | "开始做题，做完立刻知道对错" | 「刷题」页 → 沉浸式作答层，点选项即判分 | ✅ 顺（医考帮式） |
| 3 | **判错进错题本** | "错的别丢，等会儿看" | 自动回流，带 `user_answer` | ✅ 顺（零操作） |
| 4 | **复盘错题** | "这道我为什么错、我当时怎么想的" | 错题本 → 本地错题 vault → 写「我的理解/疑问」 | ⚠️ 两套错题入口并存（见 §2.2） |
| 5 | **问疑问 / 再练** | "这个知识点到底怎么回事" | vault Agent（只引用自己的文件）/ 错题重练 | ⚠️ 与讲解/提问功能重叠 |

### 2.2 现状的三个链路级问题（都能用证据说清）

1. **两套错题入口**：`学习中心 → 错题本`（DB 里的 `mistakes`）与
   `学习中心 → 本地错题`（文件夹里的 `vault_items`）**并列存在**，
   同一个东西两个家。用户今天真实用的是前者（11 条 `mistakes`），
   后者是刚迁移出来的副本（17 条）。**目标态应是：vault 是真身，错题本是它的一个视图。**
2. **"问答"能力三套重叠**：`讲解 explain`（0 条）· `提问 tutor`（0 会话）·
   `vault Agent`（新，17 条错题可问）。前两者需要 API Key 且零使用，
   第三者刚落地且**只引用用户自己的文件**（可证伪性更强）。
3. **"复习"能力两套重叠**：`记忆卡/SM-2 复习卡`（0 张）与
   `vault 的 SM-2 复习闭环`（`/api/vault/review/due` + `/grade`，17 条已接入）。
