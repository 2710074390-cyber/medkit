Research · 2026-10-27

AI 辅助学习的行业标杆
与 MedKit 的下一步

调研了五种产品范式、六项技术底座，并把结论落回这个仓库的代码行号。核心判断只有一句：MedKit 缺的不是模型，是学习者状态与教学策略之间的那一层。

对象 MedKit v0.20.0 代码 73 py / 19,088 行 测试 1,190 项 证据分级 强 / 中 / 弱

一 · 三个结构性断点

它今天是一个很好的「生成器 + 刷题器」。但行业头部已经走到 学习者状态 + 教学策略引擎 + 可验证内容 的三体闭环，模型只是执行器。三处断点，全部可在代码里指认。

A
作答流水没有进入学习者模型

bank_attempts 是全量流水，但掌握度只由错题聚合。_touch_knowledge_in 只在错题入库时被调，它记的「correct」不是「答对」，是「错题后来被攻下」。所以那个比率算的是错题攻克率，不是知识掌握率。

library.py:1353 / bank.py:22
B
题目没有稳定的知识点身份

syllabus_items.id 是稳定的哈希，bank_items.topic 与 QuestionItem.subtopic 是自由字符串，三者之间没有 join。同一个考点在三个题库里是三个字符串，永远不会合并。

schema.py:62 / db.py:219
C
错题之后是「问答」，不是「教学」

Agent 只读检索 + 引用 + 拒答，纪律很硬，但没有诊断、没有支架梯度、没有 fading、没有教回。它回答你的问题，但不改变你的状态。

prompts/mistake_agent.md:25
D
溯源是字符串对齐，不是语义蕴含

_align_hit 在整串未命中时，只要知识点前两个字出现在切片里就放行。引用对了切片、内容说错了，门禁照样 PASS。

gates/trace_check.py:14
E
解析是一整块文本

没有逐选项理由、没有误解标签、没有原文引句、没有难度标定。与 UWorld / AMBOSS 的差距不在题，在解析的教育密度——它们让每个错选项都教一次。

schema.py:62
F
排期是 SM-2 + 每题一卡

同一考点的五道错题 = 五张卡，重复复习。FSRS-6 在同保持率下比 SM-2 少约 20–30% 复习量，且按知识点合并才符合记忆的单位。

vault_index.py:415
G
悬空依赖：排期域的委托目标已被删除

bank.py:22 把「何时该复习」委托给「既有的知识点级调度（review / cards）」——这两个域在 v0.15 精简中已删。ADR-004 决策的 FSRS 实现随 core/scheduler.py 一起消失，FSRS 从未接到线上路径；现在跑的是 vault 里逐值复制的 SM-2。

二 · 五种范式与它们的护城河

A · CONSTRAINT
约束式导师
Khanmigo · Study Mode · LearnLM
约束不在模型，在编排：请求分类 → 课程检索 → 苏格拉底链 → 输出过滤。LearnLM 把「教学法指令跟随」做成训练目标。
塞拉利昂 1,763 人 RCT：50→64 百分位，≈1.8–2.5 年进度
B · LEARNER MODEL
学习者模型驱动
Birdbrain · OATutor · 松鼠 AI
能力与难度双参数（Elo 式）→ LSTM 40 维画像；BKT 在步骤级估计掌握；选「最低掌握度」的下一题。
KT 公开 AUC：BKT 0.71–0.76 → SAINT 0.82–0.85
C · CLOSED CORPUS
闭环语料 RAG
NotebookLM · Coursera Coach
ingest → chunk → embed → retrieve → 只用检索段落生成 → 逐段引用。可靠性来自闭卷，不是来自向量库。
低幻觉、可逐句核；无学习增益 RCT
D · ITEM BANK
题目银行工业
UWorld · AMBOSS · Osmosis
每个选项都有 rationale；题↔文双向交叉链接；Learning Radar 把做错的知识点在文章里标红；难度 1–5 + 预测分。
90%+ 美国医学生用 UWorld Step 1；AI 题 60% 干扰项不当
E · SIMULATION
模拟与推理训练
Geeky Medics · Quesmed · iatroX
病例脚本 + 只答被问到的角色约束；先承诺诊断再揭示；按 mark scheme 打分。iatroX 反其道：只在错误那一刻追问推理。
OSCE 反馈 d=0.74；缺考率 4.9%→0.8%；$0.51/次

四 · 目标架构：三环一图

内容环

generate → verify → calibrate → repair。在现有四道门禁之后，补「断言级蕴含」与「题目心理测量」两道。

NLI 蕴含p 值区分度答案位置
学习环

attempt → diagnose → tutor → schedule → retest。核心是把「错了」变成一个有策略的动作序列。

五类错因L0–L3 支架fading教回迁移题
元认知环

confidence → calibration → plan。学生最危险的状态不是不会，是「以为会」。

作答前自评Brier校准曲线周报

五 · 改造路线

P02–3 周
  • 给 ADR-004 重新接线：恢复 scheduler 协议，py-fsrs 默认、SM-2 legacy（1 天）
  • 全量作答入模：答对也写状态（1 天，收益覆盖全部学习视图）
  • item_kc 映射 + v11 迁移：题第一次有稳定知识点身份
  • BKT 估计器：人群先验收缩到个人后验
  • KC 级 FSRS-6：五道错题合并成一张卡
  • 逐选项解析：rationale / misconception / source_quote
  • 蕴含级溯源：替掉「前两字命中」
零新模型。全部可由历史 bank_attempts 离线回放验证。
P14–6 周
  • 五类错因诊断：知识缺口 / 概念混淆 / 审题偏差 / 推理跳跃 / 记忆衰退
  • 支架梯度状态机：L0 反问 → L1 概念 → L2 步骤 → L3 讲解
  • fading 规则：连续两次独立做对才降级
  • 教回 + 迁移检查：讲一遍，换情境再做一遍
  • 每日计划 + Tutor 评测集：40 场景 × 5 维 rubric
这一阶段才真正把「Agent」从 RAG 形态升级为策略形态。
P26–10 周
  • 虚拟病人：病例按问揭示，先承诺诊断再反馈
  • 前置知识图 + 打地基：追到两年前的那个断层
  • 题 ↔ 教材双链 + 标红：Learning Radar 的本地版
  • 移动消费面 PWA：只做约 30 个端点
这一层是医学特有的差异化，也是最难被通用聊天机器人复制的一层。
P3探索
  • IRT / CAT-lite：单题累计 ≥100 次作答后再做
  • 多模态：先心电图（图 + 结构化描述，最可验证）
  • n-of-1 教学策略试验：同 KC 随机分配两种策略
  • 成本路由：简单轮次走便宜模型，省 70–85%
先做实验，再产品化。不要用「先进」替代「有效证据」。

六 · 反面清单

不做通用聊天助手拿自己的短板打别人的长板。护城河是「你的教材 + 你的错题 + 可核引用 + 本地」。
不自建内容库AMBOSS 是 150+ 医生、1,400+ 篇文章。个人项目复制不了，也不该复制。
不做多智能体剧场已有研究显示智能体与聊天机器人的学习增益无显著差异；自主性不应超过证据成熟度。
不做没有常模的分数预测本地单用户没有参照系。做「准备度指数」，并明确标注非预测。
不先做云多租户数据根请求级化是 1–1.5 周的深水区，且要改写隐私承诺。先做局域网 PWA 验证需求。
不把「AI 生成」当质量保证系统综述：AI 题区分度偏低、无效干扰项常见，像新手写的题。
