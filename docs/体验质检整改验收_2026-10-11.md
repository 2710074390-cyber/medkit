## 二、逐条回执

### P0-1 首启向导盖住模式门 → 已修

- **改动**：`app.js` 新增 `modeGateMaybeShow()`（判据：已选模式 / 有 hash / 已见过 / **向导在显示** → 均不弹）；
  `initTab` 摘掉无条件弹门；`review-desk-review.js` 的 `maybeShowWizard`（早退分支）/ `wzDone` / `wzClose` /
  `loadConfig` 失败分支统一调用 `modeGateMaybeShow()`。
- **守卫**：`tests/browser/test_mode_gate.py::test_wizard_and_gate_are_not_shown_together`
  （清掉 `medkit-onboarded` / `medkit-wz-seen` / `medkit-mode-seen`，断言向导在场时门不可见；跳过向导后门出现）。
- **注入证伪**：把 `initTab` 改回 `if (!currentMode && !h && !_ls(MODE_SEEN_KEY)) modeGateShow();` →
  **用例变红**（`AssertionError: 向导显示期间模式门不得同时可见（P0-1）`）。

### P0-2 解析器「选项先于题干」自相矛盾 → 已修

- **改动**：`core/library.py::parse_question_text` 改**分段收集**——`option_begun` 后遇非选项行，
  题干尚未收集到内容 ⇒ 归题干并结束选项段；否则才拼到上一选项（保留多行选项兼容）。
  `question` 的 fallback 由未剥答案的原文 `text` 改为 `body`。
- **守卫**：`tests/test_bank_iq.py::test_third_party_options_before_question`（参数化：带/不带列表符）+
  `test_question_after_options_is_not_swallowed_by_last_option`。
- **注入证伪**：注入旧实现（`options[-1] += line` + fallback `text`）→ **3 条用例变红**，
  报错可见 `+ 答案：A`（答案泄漏进题干）。

### P1-3 题库错题被标成「押题卷」 → 已修

- **改动**：`library.sync_from_paper(questions, pid, source="paper")` 增参数；`core/bank.py` 传 `source="bank"`；
  `learn-study.js` 来源映射表补「题库练习」。
- **守卫**：`tests/test_bank.py::test_grade_returns_analysis_and_syncs_wrong_answer_to_mistakes`
  新增断言 `ms[0]["source"] == "bank"`。
- **注入证伪**：回退为 `sync_from_paper([q], pid=None)` → **用例变红**。

### P1-4 `**解析：**` 残留星号 → 已修

- **改动**：`ana_re` 允许 `\*{0,2}` 前缀；取值后 `.strip("*")`。
- **守卫**：`tests/test_bank_iq.py::test_bold_analysis_marker_is_stripped`。
- **注入证伪**：回退正则与 strip → **用例变红**。

### P1-5 导入无「科目」输入 → 已修

### A-1 解析补「出处」（报告 §八 第 9 条）→ 已修（轻量方案）

- **背景**：报告 §五「最值得补的一条」——解析里没有出处，医学生难以判断解析可信度。
- **决策**：采用**轻量方案 A**（展示题库题已有的 `source_type` / `source_year`），
  不引入教材页码级溯源（需动出题管线，另行立项）。
- **改动**：
  - `core/bank.grade()` 判分结果回传 `source_type` / `source_year`；
  - `library.sync_from_paper()` 与 `library.add_mistake()` 的**白名单式固定形状字典**
    同步补这两键（漏在白名单 = 静默丢字段，表现为「入库成功但字段全空」——本仓库既有踩坑注释已警示）；
  - `bank-drill.js` 判分结果、`learn-study.js` 错题详情在**解析下方**渲染「出处：真题 · 2024」；
    缺项自动省略，两者都缺则不渲染该行。
- **守卫**：`tests/test_bank.py::test_source_fields_flow_to_grade_and_mistake`。
- **注入证伪**：删掉 `add_mistake` 白名单里的 source_* 两键 → **用例变红**（`KeyError`）。
