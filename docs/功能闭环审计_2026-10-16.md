# MedKit 功能闭环审计报告（2026-10-16）

> 触发：用户反馈「有的按钮点了没反应、要刷新浏览器」「错题本里本地文件下载不出来」
> 「想知道还有哪些功能没闭环」。
> 口径：**一条结论必须有 file:line 或命令级证据**；改不动的写清为什么。
> 复核命令见文末 §5。

## 0. 什么叫「闭环」（本次采用的判据）

一个功能算闭环，必须同时满足五条：

1. **有入口**：用户能看见按钮/链接（不是只有端点）；
2. **有即时反馈**：点下去立刻有可见变化（结果、toast、spinner、禁用态）；
3. **落到真身**：数据真的写进文件/库，不是只改了内存；
4. **再进入能看到**：切走再回来 / 刷新后，状态与刚才一致；
5. **有可复核判据**：有测试或命令能证明 1–4（不靠「看起来对」）。

本次审计就是拿这五条去量每一处写操作。**第 2 与第 4 条是本次缺陷的集中区**
（「点了没反应」「要刷新才有反应」都是这两条破了）。

## 1. 本次修掉的闭环断点（4 处）

### 1.1 刷题操作栏判分后不刷新 ⇒ 用户看不到「下一题」（第 2 条破）

- **现象**：判分后操作栏里只有「上一题 / 跳过 / 收藏 / 笔记」，没有「下一题」。
- **根因**：操作栏原先内联在 `bankDrillRender()` 里（`medkit/web/js/bank-drill.js`），
  而判分走的是 `_bankShowResult()`——**不重渲染整块**（免得丢掉刚展开的解析）。
  于是「未判分 ⇒ 显示跳过」这个分支渲染出来的按钮，判分后**没人换掉**。
- **修法**：把操作栏抽成 `_bankActionsHTML()`，并给它一个容器 id `#bank_actions`；
  `bankDrillSubmit()` 判分后就地 `innerHTML` 重刷这一块。
  同时**常驻**一个 `#btn_bank_next`（未判分时也可见），文案随状态在「下一题 → / 查看结果 →」之间变。
- **证据**：`tests/browser/test_bank_drill.py::test_action_bar_has_next_button_and_auto_advances`
  （断言判分后「跳过」消失、`#btn_bank_next` 仍在且文案为「下一题」）。

### 1.2 选对后不自动进下一题（第 2 条的摩擦项）

- **修法**：新增 `_bankAutoArm(secs)`（`_BANK_AUTO_SECS = 3`）：判**对**后起倒计时，
  到点自动 `bankDrillNext()`；倒计时条可见且带「取消」按钮。
  三条刻意不做：判错不跳（要看解析）、背题模式不跳、最后一题不跳（不自动收尾）。
  打断点齐全：翻页 `_bankDrillGoto` / 切模式 / 开答题卡 / 收藏 / 笔记 / 退出 `bankDrillHide` /
  重渲染 `bankDrillRender` 都会 `_bankAutoCancel()`。
- **证据**：`tests/browser/test_bank_drill.py::test_auto_advance_is_cancellable_and_never_on_wrong_answer`。

### 1.3 进「错题本」时本地文件面板**从不加载**（第 4 条破，就是「要刷新才有反应」）

- **现象**：点侧栏「学习中心 → 错题本」，默认停在「本地文件（真身）」面板，
  但薄弱项表/错题列表/今日复习永远停在「读取中…/加载中…」，要刷新浏览器才出数据。
- **根因**：P-E 把「本地错题」并成错题本里的一个 pane 之后（`medkit/web/js/learn-vault.js`
  的 `mistakeView()`），加载数据的 `window.vaultView()` **只剩一条调用路径**——
  `showLearnView("vault")`。而合并后进入错题本走的是 `showLearnView("mistakes")`
  → `mistakeView()`（`medkit/web/js/learn.js`），**没人调 `vaultView()`**。
  切 pane 的 `#mv_tabs` 按钮也只调 `mistakeView()`。
- **修法**：把加载挂到**唯一入口**上——`mistakeView()` 在切到 `vault` pane 时
  自己调 `window.vaultView()`；`learn.js` 的 `vault` 别名分支改为只调 `mistakeView("vault")`
  （避免双份加载）。
- **证据**：`tests/browser/test_vault_view.py::test_vault_pane_loads_without_any_extra_action`
  （进入后**不做任何点击**，三块数据必须自己渲染出来）。

### 1.4 本地错题**没有下发通道** ⇒ 下载不出来（第 1 条破）

- **现象**：本地文件面板里没有任何下载入口，后端也没有下发端点。
- **根因**：`medkit/routers/vault.py` 原先只有读接口（列表/统计/单条读）与**写回**接口，
  没有 `download`。列表行是 `<button class="vault-row">`（按钮里塞不下第二个按钮）。
- **修法**：
  - 后端新增两条（都读**原始文件字节**，不重序列化——错题文件是真身，用户可以手改排版）：
    `GET /api/vault/mistakes/{path}/download`（attachment，中文名走 `filename*`）、
    `GET /api/vault/export`（按科目合并成一个 md）；
  - 前端：列表行改成 `<div class="vault-row">` + 行内 ⇩ 按钮（`event.stopPropagation()`，
    不误触详情）、详情面板加「下载这条错题的 md」、错题卡头加「⇩ 导出全部」。
- **证据**：`tests/test_vault.py::test_download_one_and_export_all`（**逐字节相等** +
  穿越仍被拦 + 不存在条目 404）、`tests/browser/test_vault_view.py::test_vault_download_row_and_export_all`。

### 1.5 题库变更后「快捷开始」与题库下拉不刷新（第 4 条破，同类缺陷）

- **现象**：导入/新建/重命名/删除/重解析/从项目导入题库后，「我的题库」列表更新了，
  但下方「开始刷题」的**快捷开始网格**与**题库下拉**仍是旧的——要刷新浏览器才出现新题库。
- **根因**：这两块是**独立渲染**（`loadBankHome()` ↔ `loadDoEntry()`，均在
  `medkit/web/js/bank.js`），而所有变更路径只调了前者。
- **修法**：新增 `refreshBankSurfaces(keepDrill)`（= `loadBankHome` + `loadDoEntry`），
  把 8 处变更调用点统一换掉（`bank.js` 6 处、`bank-import.js` 2 处）；
  并让 `loadDoEntry()` 在重建下拉时保留 `_bankState.current`（导入后新题库直接选中）。

## 3. 结构性风险（今天不坏，剥离插件时会静默失效）

`tests/test_frontend_domain_coupling.py` 守的是「核心片不得引用插件独有符号」。
它按**符号**判，判不到「核心 UI 入口由插件片**绑定事件**」这一类。实测有两处：

| 核心可见入口 | 绑定位置 | 后果 |
|---|---|---|
| 「我的」页 **保存配置 / 获取模型列表 / 测试连接 / 测试 OCR / 保存检索设置** | `medkit/web/js/review-desk.js`（插件片） | 剥离生成链后按钮**无绑定** ⇒ 点了没反应 |
| 左下角**版本号（检查更新）** | `medkit/web/js/review-desk-review.js`（插件片） | 同上 |
| 整个「我的」页的服务商卡片 / 模型下拉 / Key 存档 | `loadConfig()` 只在 `review-desk-review.js` 末尾调一次 | 剥离后「我的」页空白 |

**今天不会坏**：插件片总是随 `index.html` 加载。但 D2「把生成链降级为可选插件」一旦真做物理剥离，
这三处会**静默**失效——而现有守卫（内联处理器暴露、加载期前向引用、跨域符号）**一条都抓不到**
（它们只认内联 `on*="fn("` 与顶层符号引用，不认 `$("x").onclick = fn` 这种绑定）。
⇒ 建议（**未执行**）：剥离前先把 `loadConfig` / `saveConfig` / 版本号绑定搬进 `app.js`。

## 4. 已确认闭合的域（抽查，非穷举）

| 域 | 闭环判据 |
|---|---|
| 题库练习 | 点选项即判分 → 判错回流错题本（带 `user_answer`）→ 判对后自动下一题；`tests/browser/test_bank_drill.py` 11 项 |
| 错题重练 | 判对归档「已掌握」→ 落库（`learned:true`）→ 「只看未掌握」查不到；`test_mistake_retry_archived...` |
| 本地错题 vault | 文件是真身：写「我的理解/疑问」→ **刷新后仍在**（`test_vault_view_persists_user_notes_to_file`） |
| vault 复习（SM-2） | 评分 → 推进 `due` → 连续记住两次判「已掌握」→ 薄弱项表跟着变（`test_grade_item_sm2_and_mastery_convergence`） |
| 错题助手 | 四条硬约束有独立用例：带引用 / 无依据必须说不知道 / 编造引用被剔除 / 工具失败显性（`tests/test_vault.py`） |
| 大纲管理 / 真题考频 | 粘贴 → 草稿预览 → 确认入库 → 覆盖率即时更新（`sylRender` / `rexHeat` 均在确认后调用） |
| 数据管理 | 一键备份 / 打开目录 / 清空（含二次确认 + 自动备份）——`test_data_mgmt` |

    n = len(re.findall(r'@router\.(?:get|post|put|delete|patch)\(', f.read_text(encoding="utf-8")))
