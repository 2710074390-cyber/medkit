## 二、发现的问题（按严重级）

### P0（正确性 / 已修复）
1. **390px 窄屏横向溢出**：`.learn-grid` 子项未设 `min-width:0`，`1fr` 轨道按内容最小宽度展开（≈386px > 容器 298px），`.dash-metrics` 3 列在极窄屏仍撑宽 → 全页可横向滚动。已修复（minmax(0,1fr) + 480px 断点 2 列 + 各视图 `min-width:0` 复检通过）。
2. **JS 竞态**：`loadTutorCtx()` 未 `await fillTutorKp()`，从错题行「→ 提问」注入的知识点会被异步回调重置为空。已修复。

### P1（体验 / 已修复或已落地）
3. **学习中心信息架构**：闭环总览 + 薄弱点诊断 + 新增错题 + 讲解产物 + 提问式 + 复习计划 = 六张纵向堆卡。已重构为**「子导航 pills + 五视图」**（概览/错题本/讲解产物/提问学习/复习计划），一屏一任务，记忆上次视图（sessionStorage），对标 Linear 侧栏分层 + Anki 按 Deck 分区。
4. **错题行缺操作入口**：spec 要求每道错题可「→讲解 / →提问练习 / →标记已掌握」，实际只有「已掌握/删除」。已补齐：每行新增 `→ 讲解`、`→ 提问`（自动定位知识点并触发）、`详情`（展开选项/答案/解析/我的作答）、chip 化 meta（科目·章节·标签·答错次数·错因·来源）。
5. **讲解前成本预估缺失**：spec 要求「触发 LLM 前显示预计 token/金额」，原实现只有一句「正在生成」。已接入 `estLlmCost()`（复用 `/api/providers` 价格表）在讲解/提问启动时展示「预计 ≈ X 万 token · 约 ¥Y（参考价）」。
6. **讲解产物列表**：全文默认全部摊开（可堆数百 px）→ 已改**默认折叠、点击展开**；新增「↻ 重新生成」（删除旧+同名重生成，对应 spec §10.3 覆盖语义）、来源数显示；`复制`修复无反馈问题（原来传 `null` 按钮导致永不提示）。
7. **推荐列表与薄弱点清单重复**：两者都列知识点 → 推荐行现在带「为什么学它」信息 + 三个直达动作（→讲解 / →提问 / 铺卡）。
8. **卡片标题计数器用 float:right**：窄屏标题与计数挤压换行（如「薄弱点诊断 共 6 个知识点…」揉成一团）→ 新 `.cardh` flex 组件（标题 + 右侧计数），全站替换完成。
9. **无全局导航捷径**：新增 `Ctrl/⌘+1..5` 页签切换（对标 Linear 键盘流）。

### P2（视觉层级 / 已落地）
10. 页面标题 17px→**21px + 图标前缀**，与卡片 h2(14px) 拉开层级；侧栏「学习中心」换用书本图标（原靶心），右侧新增**红色徽章**（薄弱+需复习知识点数，Dashboard 数据回填）。
11. 空状态不统一：错题本/讲解/提问/复习四区改为统一的 `.empty`（大图标 + 副文案 + 引导），与「我的项目」空态同语言。
12. 学习中心各子视图残留的 `float:right` 全部清除。
