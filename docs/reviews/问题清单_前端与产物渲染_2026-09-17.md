## 三、交接说明（每条发现的严重性 / 状态 / 触发条件）

1. **M1-01（S2 · 已验证代码路径 / 理论利用）**：render_media line 101 image_ref 未转义。触发条件：image_ref 含 HTML。当前被 `_gate_image_refs` 门禁收敛为 `IMG{n}`，常规 LLM/用户流程不可达；建议修转义 + 补回归断言，防门禁未来被绕过。
2. **M1-02（S2 · 已验证代码路径 / 理论利用）**：showHistory 把 localStorage score/total 原样 innerHTML。触发条件：攻击者能写同源 localStorage（回环=需已有脚本执行；file:// Firefox 跨文件共享可成链）。建议强转数字或 esc。
3. **M1-03（S2 · 已验证代码路径 / 理论利用）**：retryWrong 信任 localStorage 题目集，q.media 不经 esc。触发条件同 M1-02。建议加载后删 media 字段 + 结构白名单。
4. **M1-04（S2 · 已验证缺失）**：无 CSP/安全头。触发条件：任一上述 XSS 成立时无第二道防线。建议中间件加 nosniff/frame-ancestors，产物加收紧外联的 CSP meta。
5. **M1-05（S3 · 理论）**：learnChip 未知 state 未 esc。触发条件：后端下发非已知 state 串。建议归一化未知态文案。
6. **M1-06（S3 · 理论）**：loadStart p.target 未 esc。建议 Number/esc。
7. **M1-07（S3 · 理论）**：导出文件名未 basename 清洗。建议前端过滤 `[/\\]`。

**已复核为真实有效的加固点（勿重复上报）**：
- 产物全量转义（test_u_batch3 + 探针复核）；复习手册 href 白名单对实体编码/javascript/vbscript/data/协议相对/事件属性/SVG/mXSS 均不绕过；
- md.js 先 esc 后解析（关键词硬编码、加粗/斜杠替换在已转义串上进行）；
- 押题卷数据岛 `json.dumps` + `</`→`<\/` 阻断 `</script>` 逃逸（含 `<!--<script>` 双转义态不逃逸，因值均在 JSON 字符串内）；
- Host/Origin 守卫（main.py:128，DNS rebinding + CSRF 烧钱）；
- image_ref `_gate_image_refs` 门禁；base64 内嵌图 1.2MB 上限+PyMuPDF 降采样；
- RV1 内联事件动态参数改 data-*+this（有源码级闸门测试）；
- ruff / eslint(--max-warnings 0) / check-package / 53 项渲染离线测试全绿。
