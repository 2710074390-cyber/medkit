## 1. P0 —— 立即修（学习闭环断裂 / 数据正确性命门）

### R3-01 押题卷错题池去重与回源丢失：compact 页数据不含 `id`/`sid`
- **位置**：`medkit/render/qbank_html.py:496-505`（`_questions_json_for_page` 的 compact 缺 `id`/`sid`）；消费端 `qbank_html.py:698-700`（`WRONG_POOL[String(q.id||"")||String(q.question||"").slice(0,40)]` 与 `id:q.id||"", sid:q.sid||""`）。
- **实测**：compact dict 字段为 `type/bloom/subtopic/question/options/answer/analysis/case_*` → 页内 `q.id`/`q.sid` 恒空。
- **用户影响**：押题卷判分后「同步错题到错题本」时**章节归属与题目 id 全丢**（学习中心无法定位原题）；去重键退化为「题干前 40 字」→ 同案例组/共享前缀的子题被误并漏存。R2 声称的「WRONG_POOL 按 id」（D19）只在 JS 一侧落地，数据源头缺字段致修复失效。
- **修法**：`compact.append` 补 `"id": q.get("id",""), "sid": q.get("sid","")`。

### R3-02 知识点含英文撇号 `'` → 「讲解/提问/铺卡」快捷按钮全部失效（JS 注入断链）
- **位置**：`medkit/web/js/learn.js:580,767,813`（`onclick="learnRecAction('explain','${esc(k.subject||"")}','${esc(k.name)}')"`）；公共转义 `app.js:5-6`（`esc` 把 `'`→`&#39;`）。
- **实测确认**：`onclick` 属性是**双引号**值，浏览器解析属性值时会把 `&#39;` 解码回字面 `'`，再交给 JS → `'Hodgkin's…'` 字符串提前闭合 → 点击语法错误零响应。医学知识点名高频含撇号（Hodgkin's、Cushing's、Bowman's）。
- **用户影响**：单击作无反应（仅触发 `window.onerror`「脚本异常」），理想捷径集体失效，用户只能绕道手动选知识点。
- **修法**：`learnRecAction` 改为 `data-kp/onclick="learnRecAction(this)"` + `this.dataset.kp` 承接原生文本，彻底躲开属性内 JS 解析；或参数用 `JSON.stringify` 后在 JS 侧 `replace(/'/g,'\\u0027')`。

## 2. P1 —— 本轮修（链路体验断点）

### 2.1 学习中心（A）
- **R3-03 复习/记忆卡自评按钮可双击 → 同卡被排两次**（`learn.js:1405-1406,1471-1488,1538-1546`）：`rvGrade/memGrade/rvQueueAll` 无 `disabled`/防重入，双击连发两次 `grade` → SM-2/FSRS 间隔（ease/reps）双计、下次复习被排得异常远/密；`rvQueueAll` 连点重复入队。修：进入即 `disabled`+「记录中…」，首个完成即重渲染；后端 grade 按卡做幂等。
- **R3-04 真题「粘贴分析」逐条跳过索引错位、跳过项不消失**（`learn.js:346,351-362`）：skip 处理只 `splice` 后按新索引改可见行文本，**不重算 `data-skip`、不更新「草稿确认（N 条）」计数**；再跳下一行时按旧索引 splice → 删错条目。文件上传路径（`rexFileRender`）全量重渲染正确，仅粘贴路径残留。修：粘贴分支复用全量重渲染或改按唯一 id 删除。
- **R3-22 错题本/子视图继承概览科目过滤但无指示、无切换控件**（`index.html:371-391` 无科目下拉、`learn.js:601-624,702-733`）：切到儿科后进错题本只显示儿科，页面无「科目：儿科」提示、无法在本视图改回全部科目 → 误以为错题为空/被删，形成隐形死路。修：错题本标题/计数区显示作用域 + 加联动下拉。
- **R3-23 quick-action「→ 提问」后科目下拉被重置回「全部科目」**（`learn.js:797-800` 先设 `tu_subject`，`1151-1159` 无条件重建下拉未恢复原值；讲解路径 `loadExplainCtx(subject)` 有 `preserveSubject`）：会话按该科建立但下拉显示「全部科目」，作用域口径混乱。修：`loadTutorCtx/fillTutorKp` 加 `preserveSubject`。
- **R3-24 「导出 Anki」无计数/无进行态/无失败反馈，可双击重复下载**（`learn.js:1564-1579`）：空库也提示「已开始导出」；失败无从得知。修：导出前查 `st.total`（0 张直接提示）、`fetch+blob` 下载捕获错误、请求期禁用。
- **R3-25 教师重点文件导入「解析即自动入库」，与粘贴的「草稿→确认」口径不一致**（`learn.js:261-287` vs `222-230`）：同一卡两套提交门槛，「草稿 N 条（已入库）」自相矛盾，误导入污染诊断/覆盖口径且无整体回退。修：文件流改「草稿→确认入库」两段式，或导入后给「已入库 X 条 + 一键撤销本次」。
- **R3-26 大纲科目下拉只首填后不再更新，新导入科目不进过滤项**（`learn.js:114,125` `options.length<=1` 守卫）：导入第 3 个科目后下拉无该科，需刷新生效。修：`sylLoad` 每次对比后端科目集增量并入。
- **R3-27 标记错题「已掌握」后，同名复习卡/记忆卡仍躺在到期队列**（`learn.js:830-837` `mkLearn` 只打标）：提示语已改为「仅归档标记」但仍会让用户在到期列表再见同一知识点。修：提示「同名复习卡仍在队列，可到复习计划移出」或提供联动移出开关（不静默删）。

### 2.2 建课-审核-产物（B）
- **R3-05 首启无 Key 点向导「载入示例」→ wizard 遮罩不关、压在连接页之上**（`review-desk.js:2019-2027` 无 Key 分支 `showTab("conn")` 后 `return` 未 `wzClose()`）：用户无法点连接页表单，必须再手动关盖板。修：无 Key 分支 `wzClose()` 后再 `showTab("conn")`。
- **R3-07 审核/重掷/重渲染写操作互相无并发互斥 → 快速连点或双标签保存静默丢编辑**（`routers/review.py:147,213,239`）：三者「读→改→原子写→重渲染」间无锁（只对出题线程有 RUNNING 检查），线程池并发下后写覆盖先写。修：per-pid `threading.Lock` 包住整段写关键区。
- **R3-08 `create_project`/gap 并发 check-then-create 竞态 → 双击建重复项目 + 双配额**（`routers/projects.py:60-137` 无幂等；`gap.py:204,240` 复用判定与创建分离）：两个并发请求都「未复用」→ 双建双 `allocate`；若前端自动开始生成 → 双管线双扣费。修：幂等判定+创建放进同一把 per-subject 锁，普通 create 加短窗口去重键。
- **R3-09 点「停止」不打断进行中的单次 LLM 请求 → 长时间卡 generating、后台继续烧 token、越快重开越被 409 拒**（`routers/pipeline.py:48-57` 只 set Event；`core/orchestrator.py:420-422,435-436` 仅切片前后查 cancel）：单个切片/QC 批次可达数十秒，取消期间请求仍计费；`RUNNING` 到线程 finally 才清。修：cancel 下透到 LLM 层（流式读取提前退出）＋ 加「正在取消中…」cancelling 态供前端展示。
- **R3-10 换服务商/模型后回到②建课，成本预估仍显示旧价**（`review-desk.js:501-502` `scheduleReady` 只监听 target/配比/Bloom/web；`242-266` 保存后只 `loadConfig` 不刷 ready；`app.js:286` `showTab("proj")` 只重绘配比条）：用户可能按错误价格决策建课。修：`btn_save` 回调与 `showTab("proj")` 拉 `updateReady()`。

### 2.3 后端契约与健壮性（F）
- **R3-06 少选项题答案键校验被 `max(…,4)` 放行 → 答案指向不存在选项**（`routers/review.py:137` `letters="ABCDEFGHIJ"[:max(len(opts),4)]`）：3 选项题答案 `D` 也通过校验（`:142` 只查 `c in letters`），成品出现「答案 D」但无 D 选项。修：`letters` 按下限到实际上限，去掉 `max(…,4)` 地板。
- **R3-17 `upload_asset`/`delete_asset` 对 slices.json 读-改-写无锁 → 并发上传/删除丢切片**（`routers/projects.py:318-350,387-404`）：两张图并发上传互相对旧列表写回，一张图切片索引丢失。修：复用项目原子写助手 + RLock。
- **R3-18 `realexams` 纯读也开写事务（BEGIN IMMEDIATE）→ 抢写锁偶发 500**（`core/realexams.py:43,127-129` `dbs.tx(write=True)`）：渲染/热力图并行时可能 `database is locked`。修：只读改 `tx(write=False)`。
- **R3-19 `subjects()` 逐科目重复全量扫描 N+1**（`routers/library.py:259-291` 每科 `get_mastery_view`+`rev.stats` 全量）：随科目×库规模线性变慢。修：一次性加载按 subject 分组聚合。
- **R3-20 `delete_project` 被 meta 存在性 gate 住 → meta 缺失项目目录不可视也删不掉**（`routers/projects.py:224-234` meta 缺失整段跳过；`list_projects:148-150` 跳过无 meta 目录）：损坏目录永久残留。修：base 存在即无条件 `rmtree`，提示「元数据缺失，已直接删目录」。
- **R3-21 `explain`/`tutor_start`/`tutor_answer`/`trial` 同步 LLM 接口无幂等去重 → 连点/双标签重复生成 + 双倍扣费**（`routers/library.py:353,472,494`；`pipeline.py:101-130`）：仅靠前端按钮禁用，端口不设防。修：同 kp/同契入做进程内短窗口去重；`trial` 加 per-subject 并发上限。

- **R3-13 押题卷关闭数小时/数天重开，练习计时从首开时间戳继续，出现超大读数**（`qbank_html.py:578,783` `t0=(loadState()||{}).t0||Date.now()`）：限时模式下会按累计跨会话时间误触发「到点判分」。（R2-D1 只解决了 `resetAll` 内计时归零。）修：判分后写 `t0` 快照，重开时若已 `judged` 则重置 `T0=Date.now()`。

- **R3-16 试出一题/审核台选项字母常量不一致**（`review-desk.js:1041,1507` `"ABCDEF"` vs `1495` `"ABCDEFGHIJ"`）：出 >6 选项题时试出/单题预览渲染 `undefined` 标签（产品页已支持到 J）。修：统一走 `letters(optCount)`，试出也支持 10 选项。
