## 一、项目概览

**MedKit · 医学题库工坊**：基于 Python 的本地优先桌面应用（FastAPI + 原生前端，启动器 `run_medkit.py` 调系统浏览器打开回环页面），帮助医学生从本地教材/教师重点生成题库、押题卷、复习手册与 Anki 卡片包。BYOK（自带 Key）、本地运行、数据不上云、多阶段 AI 管线。

**真实代码规模**（2026-09-20 实测）：

| 区域 | 规模 |
|---|---|
| Python 总包 | 72 个 `.py`，14,406 行 |
| 最大模块 | `core/orchestrator.py` 1,383 行；`render/qbank_html.py` 1,057 行；`core/library.py` 1,148 行；`routers/library.py` 944 行；`core/syllabus.py` 686 行；`core/db.py` 543 行 |
| 前端 | `index.html` 620 行 + `web/js/` 10 个脚本（最大 742 行）+ `web/css/` 3 个样式表 |
| 测试 | 89 个测试文件、712 个测试函数定义；离线收集 693 个用例，浏览器层 37 个测试函数 |

包结构（与 v1 描述一致）：`main.py` 入口 → `routers/*`（16 个路由模块 + `_common.py` 公共层）→ `core/*`（30 个核心模块）→ `agents/*`（7 个智能体）→ `gates/*`（5 道门禁）→ `render/*`（4 个渲染模块）。

## 三、核心模块核验结果

### 1. 配置与安全（`core/config.py`）— 全部属实

- **DPAPI 加密**：Windows 下 `CryptProtectData`（ctypes 零依赖），密文 `dpapi:` 前缀 + base64（:99,:140-145）；非 Windows/失败回退明文且**常驻提示不静默**（:132）。
- **旧明文自动升级**：读到旧明文，下次保存自动转密文（文件头注释 :6）；DPAPI 解密失败（换机/换用户）按未配置处理并留痕（:186-189）。
- **多服务商 Key 存档**：`provider_keys = {pid: {api_key, base_url, model_gen, model_qc}}`（:91）；保存时归档旧服务商，切换且未提供新 Key 时自动提升存档（`routers/config.py:55-78`），切走再切回免重填。
- **深拷贝防污染**：`copy.deepcopy(DEFAULTS)`（:220，注释记录旧实现浅拷贝污染事故）。
- **配置损坏容错**：解析失败先备份原文件（抢救 Key）再回退默认值（:229-235）；`LAST_LOAD_CORRUPT` 供前端提示（:214）。
- **勘出小笔误**：文件头注释第 5 行写成 "**dbapi**: 前缀"，实际前缀为 `dpapi:`（:99）。建议顺手修正。

### 2. 数据库底座（`core/db.py`，543 行）— 全部属实

- **SQLite + WAL + user_version 迁移**：WAL（:243），迁移 **v1→v7**（v1 五张基础表；v2 大纲；v3 真题考频；v4 source 归一；v5 cards；v6 year 列；v7 补索引），每版配 UP/DOWN（v4/v6 不可精确回滚处有明确注释说明原因与兜底）；升级前自动备份（:328-368）。
- **JSON→SQL 幂等导入**：`put_row` 按 id `INSERT OR REPLACE`（:437-446）；导入提交成功后原 JSON 改名 `*.pre-db-import-<ts>-<uuid4>.bak`（:550-554，注释解释"提交后才改名才安全"）。
- **行级写入**（机制在 `core/library.py`）：`_StoreView(dict)` 惰性加载（:159），只把改动行进 `st["rowwise"]` 并 UPSERT 这几行（:133-140,:249,:264）；SQL 模式单事务 `BEGIN IMMEDIATE` 串行读改写（:274），JSON 模式 RLock + 双文件原子写（:275）。
- **并发根治有据可查**：ADR-001 记载 K5 实测——双窗口并发各 50 次 grade/record_quiz，确定性互撞必丢 1 次、洪泛丢 49/41 次更新；复现脚本存于 `docs/archive/spikes/K5_concurrency_repro.py`。
- WAL 备份有专门处理：不能只拷主库（最新事务可能在 `-wal`），:287-288 记录了 W1 E2E 实证。

### 3. LLM 客户端（`core/llm.py`）— 全部属实

- **取消感知流式**：构造器接收 `cancel: threading.Event`（:66-67）；流式生成器在循环点检查取消，取消即 yield `canceled: True` 并停止读取（:137-138,:153），不再烧完整回复的 token。
- **用量记账按次隔离**：`core/usage.py` 用 `ContextVar`（:40），run/trial/regen 互不串账；线程池提交点显式 `copy_context().run` 包装（文件头注释 :5-7 说明 `ThreadPoolExecutor.submit` 不传播 ContextVar）。
- **JSON 稳健提取**：剥 ``` 围栏、容忍文前/文后散文、取首个 `{`/`[` 到末个 `}`/`]`（:29）。
- **重试**：`max_retries=2`（:66），仅可重试错误（timeout/429/5xx）走指数退避（:81,:119）。

### 4. 编排管线（`core/orchestrator.py`，1,383 行）— 阶段数更正，其余属实

- **九阶段**：`websearch → generating → gate1 → qc → fixing → finalizing → reviewing → rendering → done`（:42-43）。
- **可取消 + 断点续跑**：`threading.Event` 取消；每切片落 `中间产物/checkpoint.json`（:440,:464）；断点损坏时备份并从头重跑（:458）。
- **切片级并发出题**：`PIPELINE_CONCURRENCY = 3`（:36），`ThreadPoolExecutor`（:1052），结果按配额顺序回填、id 稳定。
- **查重门禁联动**：n-gram Jaccard ≥0.8 进 MedFix；题↔源包含率检测（见第五节）。
- **渲染前终检（finalizing/D2）**：`RENDER_MAX_OPTIONS = 6`（:39），仍超限/缺字段的题**剔除出产物**并追加 `人工复核清单.md`（:47,:80-87），不强行渲染；QC 契约失败批次另起小节入同一清单（:93-101）。

### 5. Agent 层（7 个，设计模式逐项核实）

| Agent | 核实结果 |
|-------|----------|
| **MedGen** | 占位符**一次性替换**防教材文本二次注入（`medgen.py:217`）；不足配额最多补 2 轮、超发按配额截断（:239,:249）；Bloom 配比占位符默认 30/40/25/5（:6） |
| **MedQC** | LLM-as-judge 分批质检；`MAX_WORKERS = 3`（:18）；契约硬闭环：校验失败→带错误明细重发 **1 次**（:63-73）→仍失败 `score=-1 不计分 + decision=BLOCKED` 进人工复核（:94-103） |
| **MedFix** | 合并策略保留 `PROVENANCE_KEYS = (sid, module, subtopic, type, case_id, case_order, …)`（`medfix.py:14`，:66 逐键回填），溯源与组结构不被新题覆盖 |
| **MedReview** | 教材浓缩型手册结构在提示词中契约化：`prompts/medreview.md` 规定「考点速记表 / 易混淆对比表 / … / 高频背诵清单」等固定小节（:10-15） |
| **MedExplain** | FTS5+jieba 检索、BM25 排序、不可用/无命中回退 bigram top-k（`core/explain.py:210,:236,:250`）；mtime 缓存命中时不重扫、不重建 FTS（:104,:175） |
| **MedTutor** | Socratic 状态机 `weak→shaky→solid→mastered`（`core/tutor.py:34`）；五类提问轮换：解释/应用/对比/预测/追溯（:11,:36），上一轮有差距则同类型追问；`cleanup_stale(days=30)` 清理不活跃会话（:189），经 `routers/library.py:928` 暴露（天数钳制 1–365） |
| **MedCards** | 讲解产物 → 3~6 张卡（`agents/medcards.py:1`，`core/cards.py:33` 上限 6、契约兜底 10）；四型：value（数值）/mnemonic（口诀）/contrast（鉴别）/concept（概念）；创建时绑定调度算法 |

### 6. 门禁系统（`gates/*`，纯本地零依赖）— 全部属实，补细节

- **Bloom**（`bloom_check.py`）：目标 `{记忆:.30, 理解:.40, 应用:.25, 创造:.05}`（:11），偏差限 0.15（:12）；小题量 `n<10` 时 fail 降级 warn（`SMALL_BANK_N=10`，:13,:27），理由是单题占比 1/n 波动且 q_id='BLOOM' 无法被 MedFix 定位。
- **去重**（`dedup_check.py`）：n-gram 尺寸 (2,3,4)（:15），题↔题 Jaccard 阈值 0.8（:16,:120-126）；题↔源改用**包含率**而非 Jaccard（:17 注释：题短源长时 Jaccard 必然偏小）；案例/选项组内跳过。
- **选项**（`options_check.py`）：R 规则子集——R1 选项数须符合题型期望（:49-52）、R12 无意义括号后缀（:60）、R14 选项数 >6 触发 MedFix、渲染前终检兜底剔除（:46-48）；答案键字母表与渲染层同口径（:19）。
- **数值**（`numeric_check.py`）：正确选项中带临床单位（mg/kg/ml/mmHg/mmol/℃/%/次每分等）的数值无源 → fail（:12,:22-26）；裸数字仅 warn（:15）。
- **溯源**（`trace_check.py`）：兼容 `[源:切片S001]` 与全角【源：】（:3）；不仅校验切片 ID 存在（:49），S2-9 起还校验知识点确在被引切片内（整串命中→前 2 字退化匹配，:15,:28），堵住"ID 真实但引用了别的切片"。

### 7. 渲染与导出（`render/*`）— 全部属实

- **题库 HTML/MD**：案例/选项组按组折叠、案例题干只出现一次（`qbank_html.py:254-265`）；保持章节序、不按 (type,id) 全库重排，组键优先 group.id 防同选项异组混排（:128-131）；搜索 + 全题型过滤 + Bloom（`data-blm`）+ **真题年份下拉筛选**（:332-335）；分页按题数计、**组作为原子不跨页拆散**，每页 ≤50 题（:327-328）。
- **押题卷 HTML**（同文件）：X 型 checkbox 多选、集合判分、localStorage 续答（作答自动保存、重开冻结计时）、计时/限时模式、答题卡、错题重练（沿用原卷题号，:610）、分组判分（:849）、打印（:578）、**成绩留存最近 10 次跨会话展示上次/最佳**（:835,:766-775）；判分后自动同步错题到学习中心（:584）；noscript 静态兜底（:588）。
- **复习手册**（`review_html.py`）：Markdown→HTML 经 `HTMLParser` 白名单消毒（:10,:19-25）；href scheme 白名单仅 http/https/锚点/同源相对路径，先剥控制字符防 `java\nscript:` 绕过（:29-38）；相对路径 img 仅当输出目录下存在同名文件才保留（:77,:108）。**阅读增强（v0.7）**：阅读进度条、字号调节、目录吸顶（`details.toc{position:sticky;top:8px}`）、回顶部按钮（:269,:276-315）。
- **Anki 导出**（`apkg.py`）：`.txt` 文本导入 + genanki 0.13.1 真包（:1,:16）；model_id/deck_id 按项目名稳定哈希防重复导入（:4）；标签 = 题型 / Bloom / 章节，标签做空格逗号消毒（:6,:69-79）。

### 8. 学习中心（`core/library.py`、`review.py`、`explain.py`、`tutor.py`、`cards.py`、`scheduler.py`）

- **双调度器协议**：`CardScheduler` Protocol（`scheduler.py:21`），FSRS（py-fsrs 6.3.2）默认、`enable_fuzzing=False` 保证可测（:6-8,:25），SM-2 legacy 可切（复用 `core/review.py` 零依赖实现），卡片按 `sched` 字段创建时绑定。
- **错题本**：四个来源——押题卷同步 / 文本 / 图片 OCR / 文件（`library.py:7`）；同步幂等：同 question 前 40 字视为重复不重复入库（:530）；外部站点导入幂等键 `sha1(subject|chapter|question[:80])`（:448-449,:495）；押题卷判分后自动同步，按钮仅兜底。
- **掌握度诊断**：错题 topic/know_tags 归并知识点（:8）；分数→状态阈值 mastered≥0.95 / solid≥0.80 / shaky≥0.60 / 余 weak（:94-95,:321-325）；薄弱点入复习队列铺卡（`review.py:162-168`）。
- **提问式学习**：会话持久化、概念状态晋升（晋升需连胜 `PASS_STREAK`）、30 天无活动自动清理。
- **复习计划**：SM-2 间隔重复 + FSRS 记忆卡双轨；低于 solid 的知识点批量入队。

## 九、结论

**MedKit 是一个工程质量优秀的本地优先 AI 应用**，v1 的定性判断成立：

1. **数据安全设计彻底**：DPAPI 加密 + 旧明文自动升级、回环守卫（含 IPv6、GET 拦截）、严格 CSP、密钥脱敏、零遥测、供应链闭包审计。
2. **存储底座扎实**：SQLite WAL + v1–v7 迁移（含不可回滚版本的诚实注释）+ 幂等导入留档 + 行级 UPSERT，并发丢失问题有 ADR、复现脚本与测试三重佐证。
3. **管线鲁棒性强**：可取消、断点续跑、并发=3、QC 契约硬闭环、渲染前终检宁可剔除不强渲染。
4. **测试与工程纪律好**：693 离线用例、家目录防污染哨兵、覆盖率只升不降、CI 对锁定闭包审计。

v1 报告的主要问题不在"捧杀方向"，而在**量化事实失实**：把 KB 字节数当行数（夸大 60 倍以上）、测试数少报约 3.6 倍、把经典脚本写成 ESM、虚构一处循环导入、误置两处特性归属。按本版第七节重排后，真实技术债集中在**前端全局作用域模块化**与**大文件可选拆分**，均不影响功能正确性，可按迭代节奏推进；另建议顺手修复 `config.py:5` 的 `dbapi` 笔误。

### D.2 mypy 清基线时顺带修复的两个真实潜伏 bug

1. **MedQC 并发质检结果结构不一致**（`agents/medqc.py`）：并发路径 `run()` 返回 `(i, dict)` 元组被存入 `results[i]`，串行路径存 dict，下游统一按 `r["issues"]` 聚合——**多批次 + 并发（默认路径）必崩**。现 `run()` 直接返回 dict，`results` 类型 `list[dict | None]`，聚合跳过 None。
