## WP-1 多场考试倒计时（#1）

**目标**：开始页从“单场日期”升级为“多场考试计划”，支持添加、编辑、删除、排序、临近提醒。

### 任务
- [ ] 1.1 数据模型：localStorage 键 `medkit-exams`（数组：`id / title / date / tag / color / remind_days`）；兼容迁移旧的 `medkit-exam-date`。
- [ ] 1.2 后端无需新增（纯前端本地）；如需持久化服务端可放 `~/.medkit/prefs.json`，本期优先 localStorage。
- [ ] 1.3 UI：开始页“考试计划”卡片区，支持新增/编辑/删除；按日期升序展示，最近一场置顶。
- [ ] 1.4 倒计时展示：距考试天数、考试标题、开场提醒（考前 3/7/14 天提示加大复习强度），多场可同时展示。
- [ ] 1.5 交互简化：表单内联编辑 + Enter 保存 + ESC 取消；删除需确认（仅本地偏好，无损数据）。

### 涉及文件
- `medkit/web/js/app.js`（`renderExamCountdown` / `setExamDate` 重构）
- `medkit/web/css/base.css`（考试卡片样式）
- `medkit/web/index.html`（开始页容器，少量结构）

### 验收
- [ ] 可添加 ≥2 场考试，刷新后保留。
- [ ] 删除单场不影响其余场次。
- [ ] 旧 `medkit-exam-date` 自动迁移为一场考试，不丢数据。
- [ ] 无考试时显示空态引导；有考试时最近一场排最前。

### 测试
- 浏览器用例：`tests/browser/test_start_exams.py`（新增/删除/迁移/排序）。
- 单元（如抽成纯函数）：`tests/test_start_exams.py`。
