# MedKit v0.18.1 · 全量代码审查修复批

> 一句话：**这一版没有新功能——把一次全仓代码审查揪出的 7 个正确性缺陷全部修掉了**，
> 其中两个是「数据悄悄出错」级别的问题。

## 修了什么（挑要紧的说）

### 1. 保存服务商配置，错题本不再「消失」

以前的毛病：在设置页保存一次服务商配置（换 Key / 换模型），**错题本目录会被静默重置回默认值**，
界面上错题像凭空消失；单次运行的 token 上限也会被一起丢掉。

现在：保存配置只改你这次填的字段，其余设置原样保留（并补了回归测试钉死）。

### 2. 判分口径统一：小写答案不再「App 里对、卷子里错」

以前的毛病：模型偶尔把答案写成小写（比如 `b`）。应用内刷题判**对**，
但**导出的押题卷**里这题永远判**错**——还会把这道「假错题」回流进错题本污染复习数据。

现在：答案在数据入口处就统一成大写，导出卷判分逻辑同步对齐。同一条答案在应用内、
题库、导出卷三处判分结论一致。

### 3. 题库「一键重解析」失败不再清空题库

以前的毛病：解析器升级后对旧题库重解析，如果中途出错（磁盘满 / 进程中断），
**题库已被删空却没填回**——界面上整库消失。

现在：删除与重建在同一事务里完成，失败即回滚，题库保持原样。

### 4. 删掉的错题，错题本里也不见了

以前的毛病：学习库里删掉一条错题，错题本文件夹里的对应文件还在——
错题助手仍会拿它回答问题，两个地方「打架」。

现在：删错题时联动把对应文件**归档**到错题本目录下的 `.trash/`（软删，你手写的
「我的理解 / 我的疑问」都保留，翻回来就能找回）。

### 5. 其他修复

- 编辑错题题干后，不再在错题本文件夹里留下旧文件名的孤儿副本（同样自动归档）；
- 外部站点做题数据导入：同一批里的重复题不再重复入库；
- 出题抽样的随机种子不再污染全局——两个项目交错运行时互不干扰；
- 网络冲突复核清单改为追加写入，不再覆盖已记录的其他待复核项。

## 对你有什么影响

- **无需任何迁移动作**：升级后直接启动即可，数据格式无变化。
- 如果你之前被「保存配置后错题本消失」困扰过：去设置里把错题本目录改回原路径即可找回
  （文件都在原位置，没有丢）。

## 安装

- **安装版**：`MedKit-Setup-0.18.1.exe`（约 50 MB）→ 一路下一步
- **绿色版**：`MedKit-0.18.1-portable.zip` → 解压双击 `MedKit.exe`
- 校验：`SHA256SUMS.txt`

首次使用：**直接就能用** —— 「刷题 → 导入题库文件」把你自备的 md / txt / json / csv 题库收进来，
判错会自动进错题本；配了 API Key 还能让错题助手只依据你自己的错题本回答问题。
