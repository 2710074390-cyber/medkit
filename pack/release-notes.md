### v0.10.1 本轮亮点

- **子步骤与线程健壮性**：在飞子步骤登记表 + 取消/异常出口补 `cancelled/failed` 终态（子步骤面板不再永久「运行中」）；门禁 MedFix / MedQC / 质检 MedFix 输入深拷贝快照——超时僵尸线程只污染副本，不再与主流程共享题目数据。
- **后端健壮性**：图片导入 200MB 读后即判（超限 400 不落盘）；meta 内容非 dict → 422 而非全局 500；`/api/llm/models` 异常归一化（不回显 base_url/响应片段）；未分类复习卡不再重复计入每科（分区互斥）；记忆卡生成在飞去重 409（连点不再双倍扣费）；短 API Key 掩码只露前 2 后 2。
- **学习中心与作用域**：自评失败（卡已被出卡动效移除）→ 重渲恢复；考试计划「考前 N 天」进入提醒窗口卡片点亮「备考冲刺提醒」（死数据变真触达）；错题本「全选」明示选中范围（全选全部 / 全选已加载 100/共 N）；批处理在途互斥+按钮禁用；切科目先按缓存即时重渲染（标签≠列表短暂错位消除）；「已掌握」行新增**清同名卡**显式入口（带确认，不静默删）。
- **网络检索后端连通性**：搜索超时 25s→75s（实测 DeepSeek Responses web_search 单次 20~60s，旧值必超）；结果提取按真实响应结构补强（`web_search_call.action.url` / message 注解与正文 URL，去片段去重）；「测试后端」0 结果时提示可重试/换关键词/换后端（不再误报失败）。实机验证：连通（9 条结果）31.6s 一次通过。
- **P3 打磨**：预设删除入口改事件绑定（id 含撇号不再击穿行内 JS）；富文本渲染器代码段不再被关键词高亮嵌套。
