## 本版主题：错题，从「数据库里的一行」变回「你自己的一个文件」

这一版只做一件事——**把错题还给你**。

此前错题存在 `~/.medkit` 的数据库里：你看不见、改不了、拷不走，换台机器就没了。
现在它是一堆 **markdown 文件**，放在你自己的文件夹里（默认 `~/文档/MedKit错题本/`），
一个文件一道题——**不装 MedKit 也能读**，可以丢进坚果云 / OneDrive / Git，换机器拷走即继续用。

配套加了一个 **Agent**：它**只依据你这个文件夹**作答，答不出就说「我库里没有相关记录」，
**绝不拿通用医学知识蒙你**。

---

### 一、错题就是文件（核心）

```text
~/文档/MedKit错题本/
├── mistakes/2026/10/2026-10-14-copd-病因.md   ← 一道题一个文件
├── notes/                                      ← 你自己的知识笔记（Agent 也会读）
├── attachments/                                ← 题目原图
└── README.md                                   ← 格式说明（首次自动生成）
```

- **字段能空就空**：只写题干也能入库，没有「必填校验」拦你。
- **随便改**：用 VS Code / Typora / 手机 Markdown App 改完，点「重建索引」即刻生效。
- **改坏了不炸**：某一条 front matter 写坏了，只那一题读不出来并单列一条告警，**不会动你的文件**。
- **删库 0 丢失**：数据库在本域里只是「可弃索引」，删掉全量重建后逐行相等（有守卫钉住）。

### 二、错题助手 Agent（只引用你的仓库）

学习中心 →**本地错题**→可问它。三条只读工具：搜你的错题 / 看薄弱项表 / 读某个文件。

四条硬规矩（都可证伪）：

1. **每个结论都带引用** `[来源: 路径#小节]`；编造路径会被剔除并如实告诉你。
2. **没有依据就说不知道**——这是它和通用聊天机器人唯一的分界线。
3. **先回应你自己写的话**（文件里的「我的理解 / 我的疑问」），不从概念定义开始泛泛而谈。
4. **工具坏了就说坏了**，不给一份"看起来完整"的空答案。

答复默认**只读**；你点「存进这个错题」，它才追加写入该文件的 `## Agent 的答复`（可整段删）。

### 三、不止问答：从「新建」到「复习」的闭环

- **新建错题直达**：粘贴，或**拍题（图片 OCR）**识别后直接落成 md。
- **薄弱项表**（零 LLM，不调模型）：按科目/章节/主题聚合，按优先级排序——**点一行即筛出该组错题**。
- **今日复习**（SM-2 排程，零 LLM）：记得 / 模糊 / 忘了 → 间隔推进；**连续记住两次即判「已掌握」**，
  于是「复习」会真的改变薄弱项表。排程字段（`last_tried` / `due` / `ease` …）写回文件的 front matter，可手改。
- **文件夹全域问**：问「我哪章最弱」「这些错有什么共性」这类跨条目的问题。

### 四、旧错题本怎么办

**「本地错题」页一键迁移**：把旧错题本导出为 vault 的 md 文件——**只新增文件，不删除、不修改旧数据**，
可反复点（幂等）。

### 需要知道的边界

- 上述**文件层 / 薄弱项 / 复习排程全部离线可用**，**不需要任何 API Key**。
- 只有「**问 Agent**」需要配服务商 Key（BYOK，Key 本地 DPAPI 加密）；没配就不显示增强、其它功能照旧。
- 「拍题 OCR」需要 MinerU Token（「我的 → 连接服务商」配置）。
- 检索目前是**关键词 + 分词**（jieba 词 + 二元组，组间 AND）；本地 embedding 检索（R5）本版未启用。

### 工程侧

- 真身：单元 **1215** / 浏览器层 **60** / 总 **1275**；ruff / mypy / eslint 全绿。
- 方案与调研：`docs/错题本地文件化与Agent助手_设计方案_2026-10-13.md`。
- 本版的 Agent 是**用真实 DeepSeek 端到端实测过的**——并因此现场修掉三处只有真模型才现形的问题
  （多词检索误拒答、轮数用尽给空答复、`max_tokens` 被推理预算吃光）。
