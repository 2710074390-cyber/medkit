## MedKit v0.10.3 · 发布产物对齐 + 三项实测性能治理（2026-09-16）

本版**必须升级**：0.10.2 的安装包/绿色版构建于 09-15 20:37，而同一版本号下当天深夜又落了四笔
实质提交（前端 JS 崩溃修复、数据管理区、日志脱敏、AGPL `LICENSE` 随包、讲解流去重竞态修复），
**产物再未重出**——用户手上的 0.10.2 不含这些修复且与文档描述不符（同号不同物）。本版重出包对齐。

### v0.10.3 亮点

- **升级即获得此前缺失的修复**：① 真题草稿 >200 条时点击分析必崩的前端缺陷；② 讲解流并发去重竞态；
  ③ 日志/错误回显中的 API Key 脱敏；④ 数据管理区（路径/占用/一键备份/清空二次确认）；
  ⑤ 乱码脏数据不再虚增掌握率分母；⑥ 安装包内随附 AGPL-3.0 许可证正文。
- **概览页明显更快**：打开「学习中心」概览此前要为统计一个数字把整张错题表全量解析，并把知识点表
  读两遍。1500 错题 / 800 知识点 / 600 复习卡的合成库实测：概览 **144.5 → 83.8ms**，
  掌握度 **50.1 → 29.7ms**，推荐 **40.9 → 23.4ms**。
- **判分/打卡写入不再「牵一发动全身」**：单条错题或知识点的写入原先把整张表删了重建
  （3000 行库单次 ~103ms）。现只写真正变化的那一行，并且按知识点名/id **定向取行**
  （不再为改一行把整表读进内存），知识点事件也合并为一次事务。
  实测：单条判分 `record_quiz` **67.6 → 15.7 → 5.1ms**，单条错题入库 `add_mistake`
  **99.8 → 0.2ms**；**批量回流/站点导入 100 条从 3.7s 降到 0.05s 以内**。
  结构性改动（批量删除、整组替换）仍走原路径，语义完全不变。
- **测试网更可信**：静默吞异常守卫从「允许 5 处」收紧为「零容忍」；修掉一个会随机翻红的
  会话清理用例（改为确定性复现触发条件）。

## MedKit v0.10.2 · 三报告整合改进 + 发布口径收口（2026-09-15）

本版把同日三份报告（工程审查 R6 / UX 走查（考前医学生视角）/ 工程质量独立核查）**去重合并**为
单一优先级清单后逐项落地。首要是**发布口径收口**：R5 的数据安全修复此前未进入发布产物——
`MedKit-Setup-0.10.1.exe` 构建于 09-01 12:48，早于修复提交 09-01 14:12，**同名同版本两个不同产物**。
本版 bump 到 0.10.2，确保用户拿到含数据安全修复的产物且版本可区分。

### v0.10.2 本轮亮点

- **修好两个「功能不可用/不可见」缺陷**：① 刷题页「铺卡（薄弱点全部入队）」按钮因前端用 GET 调 POST 路由而恒 405，**批量入队完全不可用**——现已修复，并加了**前后端方法一致性**守卫测试（全仓扫描前端调用，POST-only 路由必须显式指定 method）；② 「🧠 生成记忆卡」入口因 `window.FEATURES` 判定失效（`const` 不挂 window）而**永久不渲染**——现已修复，记忆卡 + Anki 这条链重新可达。
- **网络检索不再「看起来在工作、实际什么都没做」**：此前内置检索后端只读 `web_search.api_key`，未复用服务商 LLM Key → 正式生成时检索必然失败却仍显示「已开启」。现对齐回退口径，并在无可用 Key 时**生成前明确告警**。
- **重复题不再静默进产物**：查重未消除的题原样进题库与押题卷（同一题刷两遍）。现改为在产物页显示「⚠ 疑似重复」标记并留痕人工复核清单。
- **界面细节修复**：题库页筛选区「重置」按钮不再显示为英文字面量 `null`；头部题数与筛选计数口径统一（「共 N 题（M 张卡…）」）；押题卷回流错题的错因不再恒为「推理断链」（改为「未作答 / 未标注」）。
- **发布口径**：版本号 / CHANGELOG / 安装包名 / `version.iss` 五件套统一到 0.10.2。

## MedKit v0.10.1 · R4 全链路审查三批次完结 + 网络检索后端连通性修复（2026-09-01）

自 v0.10.0 以来的更新：R4 全链路审查批次 3（打磨 18 项，R4-09~26）全部落地 ——
上版三批次四批修复（R4-01~08/12）之后，本版补齐剩余打磨项；另修复「网络检索后端测试」
必超时/提取失败问题（用户实测「测试后端依然失败」的根因）。

### v0.10.1 本轮亮点

- **子步骤与线程健壮性**：在飞子步骤登记表 + 取消/异常出口补 `cancelled/failed` 终态（子步骤面板不再永久「运行中」）；门禁 MedFix / MedQC / 质检 MedFix 输入深拷贝快照——超时僵尸线程只污染副本，不再与主流程共享题目数据。
- **后端健壮性**：图片导入 200MB 读后即判（超限 400 不落盘）；meta 内容非 dict → 422 而非全局 500；`/api/llm/models` 异常归一化（不回显 base_url/响应片段）；未分类复习卡不再重复计入每科（分区互斥）；记忆卡生成在飞去重 409（连点不再双倍扣费）；短 API Key 掩码只露前 2 后 2。
- **学习中心与作用域**：自评失败（卡已被出卡动效移除）→ 重渲恢复；考试计划「考前 N 天」进入提醒窗口卡片点亮「备考冲刺提醒」（死数据变真触达）；错题本「全选」明示选中范围（全选全部 / 全选已加载 100/共 N）；批处理在途互斥+按钮禁用；切科目先按缓存即时重渲染（标签≠列表短暂错位消除）；「已掌握」行新增**清同名卡**显式入口（带确认，不静默删）。
- **网络检索后端连通性**：搜索超时 25s→75s（实测 DeepSeek Responses web_search 单次 20~60s，旧值必超）；结果提取按真实响应结构补强（`web_search_call.action.url` / message 注解与正文 URL，去片段去重）；「测试后端」0 结果时提示可重试/换关键词/换后端（不再误报失败）。实机验证：连通（9 条结果）31.6s 一次通过。
- **P3 打磨**：预设删除入口改事件绑定（id 含撇号不再击穿行内 JS）；富文本渲染器代码段不再被关键词高亮嵌套。
