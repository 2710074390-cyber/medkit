# MedKit v0.18.0 · 错题本变成「一个大聊天界面」

> 一句话：**错题不用你管，它自己会进错题本；错题本就一个聊天框。**
> 这一版是由你的实际使用反馈驱动的——每一条都定位到根因，不是加个按钮了事。

## 这一版做了什么

### 1. 错题做了之后，自动进错题本

以前的毛病：刷题判错后，错题只写进了数据库，而「错题本」默认展示的是你自己的文件夹 ⇒
**你打开错题本是空的**，看起来「没进去」。

现在：**判错即自动补写成错题本的 markdown 文件**，不需要任何「迁移 / 导入 / 导出」动作；
启动时还会把历史遗留的错题**一次性补齐**（只补一次，你手删过的不会复活）。

### 2. 错题本 = 一个大聊天界面

删掉了「本地文件 / 旧库」二级切换和整个旧库面板。现在进去就是**一个聊天框**：

- 空态一句话引导 + 4 条快捷提问（「我最近哪个章节最弱？」「这些错题有什么共性？」…）；
- 可以连续追问（它记得上文），逐字流式输出、可「停止生成」「重新生成」；
- 它只依据你自己的错题本作答，**答不出来会说不知道**，每条结论都带来源；
- 薄弱项 / 今日复习 / 错题列表作为次要区块放在下方。

### 3. 存储路径固定，不再让用户到处导入导出

- 错题本固定在你本机的 `~/文档/MedKit错题本/`（首次写入自动创建），**不再需要选文件夹**。
- 删掉了「选择 / 创建文件夹」「从旧错题本一键迁移」「导出全部」「单条下载」等入口。

### 4. 少解释，多上手

学习中心各页的长段「为什么这么设计」式说明被精简成短标签；新建错题表单把
「题干（唯一必填）」提到第一位。

## 对你有什么影响

- **你的数据一条没删**，路径没变；只是错题本更「会自己长」了。
- 如果你想直接在文件夹里看/改错题，仍可以直接打开 `~/文档/MedKit错题本/`。
- 「错题重练」入口仍在「刷题」页（原错题本行内的「→ 重练」随旧库面板一起移除）。

## 安装

- **安装版**：`MedKit-Setup-0.18.0.exe`（约 50 MB）→ 一路下一步
- **绿色版**：`MedKit-0.18.0-portable.zip` → 解压双击 `MedKit.exe`
- 校验：`SHA256SUMS.txt`

首次使用：**直接就能用** —— 「刷题 → 导入题库文件」把你自备的 md / txt / json / csv 题库收进来，
判错会自动进错题本；配了 API Key 还能让错题助手只依据你自己的错题本回答问题。
