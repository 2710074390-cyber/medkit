# MedKit v0.19.0 · 前端设计重构（界面换新）

> 一句话：**这一版重做了界面**——页签从 5 个收到 4 个、亮暗两套主题与配色重写、
> 加载不再只有转圈、还多了 `Ctrl+K` 命令面板。功能一个没少，路径更短了。

## 界面变化（看得见的部分）

### 1. 页签 5 → 4：今天 / 刷题 / 错题 / 设置

以前「学习中心」里还套着「概览 / 错题本 / 大纲管理」三个子页签，同一条学习数据在两处各算一遍。
现在：

- **「概览」并入「今天」**：今日待办 + 学习闭环总览 + 薄弱点诊断同屏，指标只算一次；
- **「错题」升为一级页签**：进去就是错题助手（聊天即主界面），宽屏下右侧常驻「薄弱项 /
  今日复习 / 错题列表」；
- **「大纲管理」与「真题考频」迁入「设置 → 进阶功能」**（折叠区，随出题工坊开关显隐）；
- **「我的」改名「设置」**，并按 外观 / 连接服务商 / 提示词与规则 / 数据管理 / 进阶功能 分组。
- 快捷键跟着新顺序走：`Ctrl+3` = 错题、`Ctrl+4` = 题库（`Ctrl+1` = 今天、`Ctrl+2` = 刷题、`Ctrl+5` = 设置）。

### 2. 亮色主题不再是「一张白纸」

旧版亮色下**卡片和页面底色是同一个 `#ffffff`**，界面会塌成一片；现在底色浅青灰、卡片纯白，
层次一眼可辨。暗色底也从近纯黑抬到 18% 亮度，用四级表面表达层级（而不是看不见的投影）。
控件描边对比度从 1.26:1 提到 3.77:1、成功色文字从 3.96:1 提到 6.20:1——都达到可读标准。

### 3. 加载更快「看起来」

今天 / 题库列表 / 错题列表三处在数据回来之前先画同形轮廓（骨架屏），不再是空白里的转圈；
加载完成时布局不跳。

### 4. `Ctrl+K` 命令面板（新增）

键盘党可以直接敲 `Ctrl+K`（Mac 为 `⌘K`）唤起一张可搜的命令表：跳页面、导入题库、新建错题、
错题重练、生成复习手册、切主题、一键备份、检查更新。侧栏左下角也有一个按钮能点开它
（不用记快捷键）。`↑↓` 选择 · `Enter` 执行 · `Esc` 关闭。

## 顺手修掉的一个真缺陷

**旧版「考试计划」的迁移会白做**：早期版本用单键存考试日期，新版本迁移成多场考试时
只把结果放在内存里、删掉旧键却**没写回新键** ⇒ 刷新一次，之前迁移过来的考试就消失了。
现在迁移会落盘，刷新后仍在。

## 对你有什么影响

- **无需任何迁移动作**：升级后直接启动即可，数据格式与目录结构都没变。
- 界面位置变了：想找「大纲管理」去「设置 → 进阶功能」；想看错题直接点侧栏「错题」。

## 安装

- **安装版**：`MedKit-Setup-0.19.0.exe`（约 50 MB）→ 一路下一步
- **绿色版**：`MedKit-0.19.0-portable.zip` → 解压双击 `MedKit.exe`
- 校验：`SHA256SUMS.txt`

首次使用：**直接就能用** —— 「刷题 → 导入题库文件」把你自备的 md / txt / json / csv 题库收进来，
判错会自动进错题本；配了 API Key 还能让错题助手只依据你自己的错题本回答问题。
