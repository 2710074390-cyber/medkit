# MedKit v0.17.0 · 奥卡姆精简（第二轮）

> 一句话：**把产品收敛回它真正在被用的那一半。**
> 这一版删掉的全是**实测零使用**的功能，同时把三件「不能丢的能力」搬了家而不是删掉。

## 这一版做了什么

### 1. 删掉讲解 / 提问 / 记忆卡·复习卡三个域

依据不是「我觉得没用」，而是**你自己机器上的数据**：

| 表 | 行数 |
|---|---|
| `explains`（讲解产物） | **0** |
| `tutor_sessions`（提问会话） | **0** |
| `cards`（记忆卡） | **0** |
| `review_cards`（复习卡） | **0** |

而这四个是活的：`bank_items` **460 题** · `bank_attempts` **22 次作答** · `vault_items` **17 条** · `mistakes` **11 条**。

全仓代码里零数据的功能合计 **13,931 行 = 48.6%**。顺带发现一件反直觉的事：
**模块级死代码是 0 个** —— 这些代码互相 import、被测试覆盖，静态看「全是活的」。
死的是**功能**，不是代码。所以这次精简只能是「产品决策 + 连带删除」。

**能力没丢，搬了家**：
- **SM-2 复习排程**搬进错题 vault —— 「今日该复习哪几道」照旧可用；
- **Anki 卡样预览 / 导入指引**搬回出题工坊的项目页（原本借住在复习卡代码里）；
- **科目管理**入口接回错题本。

### 2. 错题入口合并：一个概念只有一个家

以前学习中心并列两个入口——「错题本」（数据库里的）和「本地错题」（你自己文件夹里的）。
同一个东西两个家，你得先想清楚「哪个才是我的错题」。

现在**只剩「错题本」一个入口**，进去后顶部切换来源：**本地文件（真身）** / 旧库（导入/扫描）。
默认是前者。老书签、历史链接仍然打得开（不制造断链）。

### 3. 清掉上一轮删功能时漏掉的样式（−121 行）

上一版删掉错题归因时，代码删干净了、**样式没删**：`learn.css` 里 311 行有 **105 行（33.8%）**
在给已经不存在的界面化妆，全仓 385 个样式类里 **41 个是孤儿**。
这一版清干净了，并加了**守卫**：以后删界面忘了删样式，测试会红。

## 对你有什么影响

- **首启更快、界面更少**：学习中心从 6 个子视图收敛到 **3 个**（概览 / 错题本 / 大纲管理）。
- **出题工坊仍默认关闭**（「我的 → 出题工坊」一个开关打开）—— 这条没变。
- **你的数据一条没删**：旧表、旧字段全部保留，只是不再有界面去读写它们。
- 侧栏「刷题」页只剩「做题」（原「复习（卡片）」随域移除）。

## 安装

- **安装版**：`MedKit-Setup-0.17.0.exe`（约 50 MB）→ 一路下一步
- **绿色版**：`MedKit-0.17.0-portable.zip` → 解压双击 `MedKit.exe`
- 校验：`SHA256SUMS.txt`

首次使用：**直接就能用** —— 「刷题 → 导入题库文件」把你自备的 md / txt / json / csv 题库收进来即可，
不联网、不需要 API Key。错题会自动回流到错题本，可以在那儿写「我的理解 / 我的疑问」；
配了 API Key 还能让助手**只依据你自己的错题库**回答问题（答不出来它会说「不知道」）。
