## 本版主题：奥卡姆精简 —— 把产品收敛回它真正在被用的那一半

**本版删掉了一批功能**，所以先说清楚依据：我统计了这台机器上 `~/.medkit/` 的真实使用数据。

| 数据表 | 行数 | 归属 |
|---|---:|---|
| `bank_items`（题库题目） | **220** | ✅ 题库刷题 |
| `banks` / `bank_sources` | 1 / 1 | ✅ 题库刷题 |
| `mistakes` / `explains` | 7 / 107 | ⚠️ 均为体验走查副产物 |
| `error_events`（错题归因流水） | **0** | ❌ 从未使用 |
| `kp_alias`（知识点对齐） | **0** | ❌ 从未使用 |
| `cards` / `review_cards` | **0 / 0** | ❌ 从未使用 |
| `syllabus_items` / `realexam_freq` | **0 / 0** | ❌ 从未使用 |
| `tutor_sessions` | **0** | ❌ 从未使用 |

配套证据：`~/.medkit/projects/` **空**（生成链从未产出过课题）、`sessions/` **空**；
近 10 个 git 提交有 9 个在改「题库导入 / 刷题 / 重解析」。

**结论**：2.4 万行 Python + 8.4 千行 JS 的工程体量，在真实使用中只被触发了**一个域**。
于是本版按奥卡姆剃刀收敛：**把「刷题 + 错题复盘」这条被验证过的闭环做干净，其余功能降级或移除**。

---

### 一、首启不再有门槛（原 P1）

- **删掉「错题 / 生成」双模式门**与**3 步新手向导**。此前真首启时向导会盖住模式门、
  模式门点不动——新用户第一屏就卡住（体验质检 `docs/体验质检_医学生视角_2026-10-10.md` §二 P0-1 实测）。
  现在：进入即落在「开始」页，**无任何遮罩**。
- **「练习」并入「刷题」**（6 → 5 个一级页签）：导入自备题库与开始刷题不再跨页签。
- **「开始」页改为刷题向落地页**：空状态引导从「三步出题」改为「导入题库 → 马上刷题」。

### 二、删除错题归因（EP-01）整域

- **删除 30 个端点**（`/api/errors/*`）与 15 个后端文件：五阶段归因管线、知识点 ID 对齐、
  元认知统计（校准曲线 / Brier 分数 / 热力图 / 跨轮次迁移矩阵 / 减法清单）、苏格拉底复习、
  错题检索、Anki `.apkg` 导入、Markdown 复盘笔记、图像录入完整管线。
- **删除前端三个视图**：元认知、拍照录入（自动归因）、错题检索框。
- **图像录入降级**：保留一个轻量「拍题(图片 OCR)」按钮——只把图转成文本回填，
  不做能力判定、不过闸门、不跑归因。需要它请在「我的 → 连接服务商」配 MinerU Token。
- **保留**：错题本（列表 / 按科目章节分组 / → 重练 / 批量导入导出 / 收藏 / 笔记）、
  讲解产物、提问式学习、SM-2 复习卡。

### 三、出题工坊降级为可选插件（默认关闭）

「教材 → AI 出题」这条链（题库 / 押题卷 / 复习手册 / Anki 导出）**默认不出现在侧栏**——
它是「另一条产品线」，要上传教材、配 API Key、理解题型配比与门禁规则。

- 默认侧栏只有 4 个页签：`开始` / `刷题` / `学习中心` / `我的`。
- 想用：**「我的 → 出题工坊」勾一下**，侧栏立刻出现「题库」页签，
  学习中心出现「大纲管理」、「我的」出现「网络检索」、「开始」页出现「最近项目」。
- 关闭状态下 `#bank` 链接会被拒并落回「开始」——不是视觉隐藏。
- **代码完整保留**（不是物理剥离）：一个勾选即恢复全部能力。

### 你的数据

- **一律不删**。`kp_alias` / `error_events` 两张表与 `mistakes` 的 v8 列全部保留，数据库 schema 不降级。
- 题库、错题本、复习卡、项目与产物**原样可读**，无需任何迁移动作。

### 升级须知

- 原来靠「错题归因 / 元认知」的数据看板**本版不再提供**；错题本本身与「→ 重练」闭环不受影响。
- 原来直接点侧栏「题库」出题的用户：去「我的 → 出题工坊」打开开关即可，其余用法不变。
- EP-01 相关的设计文档已移入 `docs/archive/ep-01/`（保留历史，不再维护）。

### 工程侧

- 真身：单元 **1185** / 浏览器层 **56** / 总 **1241**（原 1536 / 98 / 1634）；mypy 源文件 89 → **77**。
- ruff / mypy / eslint 全绿；浏览器层 chromium 全绿。
- 视觉能力判定（`VISION_MODEL_HINTS` / `looks_like_vision`）从 `core/vision.py` 下沉到
  `core/modelcatalog.py`，顺带**消除了这两个模块的循环依赖**（行为零变化）。
- 方案与依据：`docs/重构设计方案_奥卡姆精简_2026-10-13.md`。
