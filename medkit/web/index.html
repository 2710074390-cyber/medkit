上传素材（教材 / 教师重点为必填）

素材要求与建议（先看这里）
格式：PDF（须带文本层）/ DOCX / MD / TXT / 图片（png·jpg，需开启 OCR）；单文件 ≤ 200 MB；扫描件 PDF 会自动走 MinerU OCR 识别并加入输入
为什么必填：教材 = 题目的事实依据（每题必须可溯源）；教师重点 = 考点锚定（决定哪些内容多出题）
最佳实践：一次只传 一个章节或一篇——100 题 ≈ 单章 30~80 页；教材建议带章节标题（第X章 / 一、 / 1.1 / ##），可自动按章分配题数
教师重点：提纲式、含术语/数值/考点即可，2~10 页最理想；超过约 4000 字仅前 4000 字参与锚定
隐私提示：启用 OCR 时扫描件会上传至 MinerU 云端识别；启用网络检索时检索词发送到所选搜索后端；普通文本 PDF 全程本机解析。
教材（必填）PDF(文本层)/DOCX/MD/TXT，可多个文件；支持拖拽
教师重点（必填）课堂重点/复习提纲，作为考点锚定；支持拖拽
自备真题 · 补充资料（可选）
真题仅用于高频考点优先 + 题型风格校准（严禁照抄原题，新题仍以教材为唯一依据）； 资料作为教材的补充上下文（课件/笔记/大纲；与教材冲突时以教材为准）
