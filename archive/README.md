# archive/ —— 旧构建快照归档（不入库，见根 `.gitignore`）

> 2026-09-17 整理：把根目录下 16 个历史构建快照集中到这里，根目录条目从 27 收敛到 12。

## 目录结构

```
archive/
├── builds/          ← 原 build-old-*（PyInstaller 中间产物，8 个版本）
│   ├── 0.10.1/
│   ├── 0.10.2-pre-u10/
│   ├── 0.10.2-pre-u17/
│   ├── 0.10.3-pre-v09/ … -pre-v15/
└── dist/            ← 原 dist-old-*（绿色版产物，8 个版本）
    ├── 0.10.1-pre-r5/
    ├── 0.10.2-pre-u10/ …
    └── 0.10.3-pre-v15/
```

> 目录名去掉了 `build-old-` / `dist-old-` 前缀（父目录已表达该语义）。
> 体积合计约 **1.45 GB**（builds ≈ 470 MB，dist ≈ 980 MB）。

## 用途与边界

- **仅作打包机制取证**：查「某版本的 spec/iss/excludes 当时怎么配的」「产物里到底含什么」。
- ⚠️ **不得作为结论依据**：审查/验收报告一律引用 `HEAD` 的 `file:line`；
  旧产物只用于回溯打包行为（与 `docs/reviews/问题清单_供应链构建发布_2026-09-17.md` §0 的口径一致）。
- **当前活跃产物**仍在根目录：`build/`（中间产物）、`dist/MedKit/`（绿色版）、
  `dist-installer/`（安装包，约 1.2 GB）。

## 维护

- 新增出包留档请直接放到 `archive/builds/` / `archive/dist/` 下，**不要再在根目录创建 `*-old-*`**。
- 整棵 `archive/` 已被 `.gitignore` 忽略；需要长期保留的历史产物请另行备份（本目录不随仓库分发）。
